# Scientific illustrations / 科学示意图

## Current AI-generated figures / 当前 AI 生成图

The four maintained scientific figures are complete built-in imagegen outputs in [ai-generated](ai-generated/README.md): architecture, physical references, concise technical route and the shared seven-repository roadmap. Both main READMEs use these assets. Exact prompts, original paths, dimensions and SHA-256 identities are recorded in the [manifest](ai-generated/manifest.json) and [prompts](ai-generated/prompts.json).

当前四张科学图均为内置 imagegen 的完整输出，两份主 README 共用原始 PNG。首图通过带本地化标题/描述的 SVG 外壳兼容原有契约，不增加图形或渲染文本。图像是说明性示意，不是测量、求解器输出、性能评分或科学认证。精确公式、单位与边界以实现指南和源码为准。

## Historical assets / 历史资产

`vision-zh.png` and `vision-en.png` are retained legacy concept artwork and are no longer the selected README illustrations. The earlier directory note attributed them to built-in image generation; this round does not supply a new generation receipt for those historical files. The `atlas-v2` and `acceptance` SVGs remain historical code-drawn assets, accessible for source inspection and existing safety gates; they are not the current AI-generated figures.

旧愿景图、atlas-v2 与 acceptance 图保留用于历史检查，不冒充本轮生成结果。原有图谱安全检查继续有效。
