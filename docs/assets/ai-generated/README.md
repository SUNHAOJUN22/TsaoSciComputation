# AI-generated scientific figures / AI 生成科学示意图

These four complete PNGs are the current scientific illustrations. They were generated with the built-in `image_gen.imagegen` tool and copied byte-for-byte; no code-drawn text, shape overlay, montage, resizing or raster postprocessing was added. The visible AI/illustrative label belongs to each generated image.

四张完整 PNG 为当前科学图，均由内置 imagegen 生成并原样复制，没有代码绘制文字、图形覆盖、拼贴、缩放或后期改图。图片中的 AI/示意性标注由生成图自身承载。

| File | Purpose / 用途 | Interpretation / 解释 |
|---|---|---|
| [architecture.png](architecture.png) | Scientific-computation architecture / 计算架构 | Contracts, exact-plan authorization, parser and review boundaries / 合同、精确计划授权、解析及审阅边界 |
| [algorithm.png](algorithm.png) | Implemented physical references / 已实现物理参考 | Ideal chain, Poiseuille flow, dimensionless oscillator and independent uncertainty / 理想链、泊肃叶流、无量纲振子与独立不确定度 |
| [roadmap.png](roadmap.png) | Concise technical route / 简洁技术路线 | Final-pair max tolerance, positive accumulation and artifact identity / 末两点最大容差、正积累和工件身份 |
| [seven-repo-roadmap.png](seven-repo-roadmap.png) | Shared research overview / 共享科研总路线 | Proposed interfaces among seven independent repositories / 七个独立仓库之间的拟议接口 |

[Manifest](manifest.json) records original output paths, byte hashes, sizes, dimensions, observer timestamps when available and `null` for an unreturned model identifier. [Exact prompts](prompts.json) retain all three initial calls, both corrective imagegen edits and the shared overview prompt. The architecture molecular icon and roadmap balance labels were corrected with imagegen; their superseded attempts are not the current figures.
